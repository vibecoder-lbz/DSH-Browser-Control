# DeepSeek whale icon

Source artwork: https://cdn.deepseek.com/platform/favicon.png (retrieved from DeepSeek's official CDN).

The extension uses transparent PNG variants at 16, 32, 48 and 128 pixels, recolored to DeepSeek blue (`#4D6BFE`) for toolbar readability. The original source PNG is retained beside them.

The artwork identifies DeepSeek; this browser-control extension is a local custom DSH plugin and does not claim official endorsement.
